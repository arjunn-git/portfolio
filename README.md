Inspired by the immersive storytelling and spatial interactions of **Active Theory**, the site presents an original visual identity tailored to creative web engineering.

## 6. Environment Variables & Setup

Copy `.env.example` to `.env`:

```bash
# Optional API endpoint for contact form submissions
VITE_CONTACT_API_URL=

# Optional EmailJS keys
VITE_EMAILJS_SERVICE_ID=
VITE_EMAILJS_TEMPLATE_ID=
VITE_EMAILJS_PUBLIC_KEY=

# Optional LinkedIn profile URL (displays link when configured)
VITE_LINKEDIN_URL=
```

> **Note on Email Service:** If `VITE_CONTACT_API_URL` or `VITE_EMAILJS_PUBLIC_KEY` is not set, the contact form explicitly displays a pending status banner and directs visitors to the direct `Email Me` button or one-click `Copy Email` action.
